よくある質問

別の端末とデータが同期されません

同じApple IDでiCloudにサインインしていること、設定 → Apple ID → iCloud → App間の同期でカナエボシがオンになっていることをご確認ください。同期には少し時間がかかることがあります。

機種変更したらデータは移りますか

iCloudの同期をオンにしていれば、新しい端末で同じApple IDにサインインすると戻ってきます。写真も一緒に引き継がれます。

念のため控えを残しておきたい場合は、設定 → データ → 「バックアップを書き出す」でファイルとして保存できます。同じ画面の「バックアップから復元」で戻せます。

削除した項目を元に戻したい

削除したものは「最近削除した夢」に30日間残ります。そこから元に戻せます。30日を過ぎると自動的に完全に削除されます。

写真は何枚まで入れられますか

1つの項目につき最大6枚です。保存するときに自動で縮小しているので、端末の容量を大きく圧迫することはありません。

ウィジェットが更新されません

ウィジェットはiOSが決めたタイミングで更新されるため、アプリでの変更がすぐに反映されないことがあります。アプリを開き直すと更新されます。

見た目の色を変えたい

設定 → 外観から、ライト・ダークの切り替えと8種類のテーマを選べます。ウィジェットの色も一緒に変わります。

お金はかかりますか

かかりません。すべての機能を無料でお使いいただけます。
